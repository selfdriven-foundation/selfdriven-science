The founding commitment

Where a claim can become an experiment, test it openly.

Where a claim about how the world works can be turned into a reproducible experiment, it should be tested openly, independently and adversarially. No organisation owns the conclusions.

No experiment proves the whole theory.

The lifecycle of a claim

From a sentence to a replicated finding.

Every result travels the same path. Each stage can be performed by a different group, at a different institution — and each can fail independently, which is itself a result worth keeping.

  1. 01 · Specify

    Preregister

    Hypothesis, null, rules, measurements and analysis are written down and hashed before results exist.

  2. 02 · Build

    Implement

    Independent teams build to the specification — not by copying the reference code — in any language.

  3. 03 · Run

    Execute

    Registered runs execute across university, HPC and independent nodes. Each emits a signed manifest.

  4. 04 · Analyse

    Replicate

    Blinded analysis and independent replication test whether the effect survives new hands and new code.

  5. 05 · Contest

    Challenge

    Adversarial review hunts for artefacts and hidden assumptions. Surviving a challenge strengthens the claim.

Principles

Ten principles. One that matters most.

The commitments every participant shares — whatever they believe about the theory being tested.

  • 01

    Testability before advocacy

    Claims are expressed as falsifiable propositions wherever possible — not positions to be defended.

  • 02

    Specification before execution

    The experiment is the spec. It is defined and frozen before any results are observed.

  • 03

    Independence of implementation

    Confidence grows when independent programs — not shared code — reproduce the same phenomenon.

  • 04

    Separation of roles

    Hypothesis, implementation, execution and analysis are kept apart wherever practical.

  • 05

    Negative results are first-class

    A finding that fails to reproduce is retained, indexed and discoverable — never quietly dropped.

  • 06

    Provenance is evidence

    Software version, parameters, seeds and analysis procedure are integral parts of a result.

  • 07

    Criticism is encouraged

    A result should become stronger by surviving challenge. A good challenge is a contribution.

  • 08

    Institutional autonomy

    Participating institutions stay scientifically independent. Contribute one element or many.

  • 09

    Open evidence by default

    Specifications, implementations, results and critiques default to public availability.

  • 10

    No experiment proves the whole theory

    Evidence applies to individual claims, not to a worldview.

Governance

Eight areas of focus, adapted for open science.

The selfdriven Foundation organises every entity around the same eight areas — coordinated by human conductors, executed by many independent hands.

  • 01

    Direction

    Research program, founding questions and the protocol roadmap.

  • 02

    Engagement

    Institutional partnerships, adversarial collaboration and invitations.

  • 03

    Enablement

    Specifications, test vectors and onboarding for independent implementers.

  • 04

    Protocols

    Experiment schemas, run manifests, provenance formats and the evidence graph.

  • 05

    Sustainability

    Open infrastructure, compute federation and long-term archival.

  • 06

    Processes

    Preregistration, execution, replication and the statistical protocol.

  • 07

    Accountability

    Reproducibility status, negative-result retention and challenge records.

  • 08

    Organisational

    Federation of working groups, the Protocol Council and decentralised nodes.

The evidence graph

Papers are views. The graph is the record.

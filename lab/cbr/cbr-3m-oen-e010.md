# 2. Scientific Question

CBR-E010 asks:

> **Does the computational system developed through E006–E009 reproduce specific quantitative relationships associated with weak-field relativistic gravity without those relationships being explicitly encoded into its local rules?**

This is deliberately different from asking whether the model:

- looks gravitational;
- produces attraction;
- produces curved trajectories;
- has a limiting propagation speed.

E010 asks whether independently measured quantities satisfy known numerical relationships.

The progression is:

\[
\boxed{
\text{qualitative emergence}
\rightarrow
\text{quantitative correspondence}.
}
\]

# 3. Core Hypothesis

### CBR-H010

A computational substrate satisfying the prior CBR-OEN requirements can enter a regime in which independently emergent:

- source strength;
- metric distortion;
- clock behaviour;
- signal propagation;
- probe motion

obey mutually consistent weak-field relationships equivalent, after a single calibrated unit mapping, to the corresponding predictions of relativistic gravity.

Symbolically:

\[
\text{CBR observables}
\xrightarrow{\text{single calibration}}
\text{GR weak-field observables}.
\]

The important phrase is:

\[
\boxed{\text{single calibration}}.
\]

Different experiments must not each receive their own arbitrary fitting constants.

# 4. Null Hypothesis

The null hypothesis is:

> Apparent gravitational similarities cannot simultaneously reproduce multiple independent weak-field predictions using one consistent parameter mapping, and any apparent agreement requires separate tuning of individual phenomena.

In particular, the null permits:

- trajectory deflection without correct clock effects;
- clock effects without correct propagation delay;
- arbitrary source scaling;
- incompatible coupling constants;
- inconsistent distance dependence.

A valid correspondence requires these measurements to agree with each other.

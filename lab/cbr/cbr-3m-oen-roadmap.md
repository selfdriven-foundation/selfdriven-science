# CBR Open Experimental Network
## Experimental Roadmap v1.0
### From Geometry-Free Computation to Quantitative Physical Correspondence

---

# 1. Purpose

The **CBR-OEN Experimental Roadmap v1.0** defines the first complete experimental programme for testing Compute-Based Reality (CBR) as a falsifiable scientific framework.

It integrates experiments:

\[
\text{CBR-E001}
\rightarrow
\text{CBR-E010}
\]

into a single dependency structure.

The roadmap specifies:

- what each experiment tests;
- what must already be established before it begins;
- what counts as success;
- what counts as failure;
- what evidence is required to advance;
- when the programme should stop;
- when a hypothesis should be revised;
- which institutional groups should perform each function;
- how evidence should accumulate across the programme.

The purpose is not to create a linear march toward a predetermined conclusion.

The purpose is to create a sequence in which increasingly strong physical claims are permitted only when weaker foundational claims survive independent testing.

The central principle is:

> **Every later experiment must earn its assumptions from earlier experiments.**

---

# 2. Founding Scientific Principle

CBR-OEN does not exist to prove Compute-Based Reality.

It exists to make Compute-Based Reality testable.

Accordingly:

\[
\boxed{
\text{failure is an experimental result}
}
\]

and:

\[
\boxed{
\text{success at one level does not imply success at the next}.
}
\]

The programme must therefore preserve negative results, contradictions and failed replications as first-class scientific evidence.

# 5. Scientific Gating Principle

The programme must not advance merely because an experiment produces an interesting result.

Each stage receives one of four outcomes:

```text
GO
GO-WITH-QUALIFICATION
REVISE
STOP
```

### GO

The primary claim is independently supported strongly enough to justify downstream experiments.

### GO-WITH-QUALIFICATION

A narrower phenomenon was supported, but later experiments must adopt explicitly reduced claims.

### REVISE

The experiment did not support its current hypothesis, but evidence suggests a plausible alternative formulation worth preregistering.

### STOP

A foundational requirement failed in a way that invalidates the dependent experimental branch.

STOP does not necessarily terminate all CBR research.

It terminates the specific dependency chain that requires the failed proposition.

# 6. Evidence Thresholds

CBR-OEN distinguishes three replication levels.

### R1 — Computational Reproducibility

Same:

- specification;
- implementation;
- seed;
- environment

reproduces the result.

### R2 — Independent Implementation Reproduction

An independently written implementation reproduces the phenomenon.

### R3 — Institutional Replication

An independent organisation reproduces the preregistered result.

For experiments E001–E005, R2 may be sufficient for exploratory downstream work.

For strong physical claims in E006–E010:

\[
\boxed{
R3
}
\]

should normally be required before the result is considered established.

- no coordinates;
- no target dimension;
- local rewrite rules.

\[
